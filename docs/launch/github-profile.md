## From experimentation to production.

We’re a software lab developing, launching, and growing software products, with experimentation shaping what we build and how we build it.

### Projects

- **[TypeChinese](https://typechinese.io/)** — Chinese typing practice with vocabulary and real passages.
- **[RxRecall](https://rx-recall.com/)** — Drug-name review and a searchable drug library for pharmacy students.
- **[Orb UI](https://orb-ui.com/)** — Open-source React components for voice agents.
- **[Keyboard Layout Tester](https://keyboard.experimental.software/)** — Test and compare keyboard layouts, including Dvorak and Colemak.
- **[Flight Currency](https://chromewebstore.google.com/detail/google-flights-currency-s/nameliafoadmpledepdbcgnogcnfiemo)** — A currency extension for Google Flights.
- **[badminton.fyi](https://badminton.fyi/)** — Compare badminton racket specifications, prices, and popularity.
