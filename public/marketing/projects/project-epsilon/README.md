# Project Epsilon teaser

Coming-soon card, placed first in the gallery. No destination URL or product details.

The cover follows the Experimental Software White Room guide: white, ink, pale surface, and one small acid-yellow accent. General Sans Regular provides the title; Meslo LG S provides the labels. The epsilon is a separate project motif, not a modification of the Original Outlier logo.

`cover.svg` is the self-contained vector source with outlined type. `cover.webp` is the 1200 × 630 gallery export. Rebuild with `node scripts/build-epsilon-artwork.mjs` after preparing the existing brand fonts. Colors come from `public/brand/tokens.json`.

The card uses a muted Coming Soon badge, has no link or interactive controls, and omits the Explore action. The earlier generated sculpture was rejected and is not served by this card.
